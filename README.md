# Ayush Dwivedi — Portfolio

Personal portfolio for Ayush Dwivedi, featuring software, AI, computer vision, backend, and embedded systems work.

## Run locally

This version is a self-contained static page in `index.html`.

```bash
npm install
npm run dev
npm run build
```

The existing Vite build outputs the deployable site to `dist/`. GitHub Actions also publishes to GitHub Pages on pushes to `main`; the project is connected to Vercel for production hosting.
